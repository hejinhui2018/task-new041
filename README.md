# KioskFlow 展示终端流程验收台

给展馆互动屏做的**流程编排 + 中断/断电恢复验收**工具，全部在浏览器本地运行
（React + TypeScript + Vite，无后端）。

针对现场事故：**讲解中途切换展厅，屏幕恢复后跳过了必看安全提示，只能整机重启**。
KioskFlow 把「页面、停留时长、前置条件、可中断提示」组成一条真实流程，
让你在验收台上复现这类问题，并验证恢复策略：**断电恢复绝不能绕过必经安全步骤**。

## 它能验收什么

- **真实流程模型**：每页有模式（自动播放 / 人工讲解）、停留时长、
  前置条件（必须已完成的事实）、可中断提示（阻塞式安全提示，必须触摸确认）。
- **五类现场操作模拟**：触摸确认、下一步、停留超时、无障碍暂停、断电/上电。
- **三块互动屏**：入口 / 序厅 / 尾厅，各自独立计时、独立状态，顶部标签页切换。
- **幂等触发**：触摸事件携带一次性 nonce，同一块屏重复/陈旧触发不会推进两次；
  重复到时信号不会把一页偷偷播两遍。
- **冷启动门禁**：断电或浏览器刷新后，强制安全事实一律失效，位置回退到最早的
  强制提示页，未重新确认前无法继续；尝试用旧 nonce、直接下一步均无效。
- **可观测**：当前屏幕、模拟时钟、已完成事实、触摸 nonce、阻断原因、事件日志全程可见。
- **验收辅助**：
  - **替换一页**：改任意页的标题/正文/模式/时长/提示/前置条件，可立即演练，可撤销；
  - **跳到故障点**：时间线任意跳转（仍走前置条件守卫，跳不过就阻断），
    或一键「强进喂食演示（跳过规则确认）」复现违规操作；
  - **恢复前后差异**：对比断电瞬间与恢复后的屏幕、状态、失效安全事实与回退页数；
  - **撤销 / 重做**：跨页、触摸确认、断电上电、替换页面都在历史栈内（高频计时不入栈）；
  - **刷新恢复**：状态写入 `localStorage`，刷新页面等价于设备重新上电，走同一套冷启动门禁；
  - **重置**：清空当前屏流程与本地存档。

## 内置流程：海岸生态展

| # | 页面 | 模式 | 可中断提示 / 前置条件 |
|---|------|------|----------------------|
| 1 | 入口 · 安全提示 | 自动 | ⚠ 强制安全提示 |
| 2 | 海岸全景 | 自动 | 需确认入口安全 |
| 3 | 潮间带讲解 | **人工** | 需看完海岸全景 |
| 4 | 潮池生物特写 | 自动 | 需听完潮间带讲解 |
| 5 | 互动触摸池 · 规则 | **人工** | ⚠ 强制安全提示 |
| 6 | 触摸池喂食演示 | **人工** | 需确认触摸池规则 |
| 7 | 海鸟迁徙地图 | 自动 | 需完成喂食演示 |
| 8 | 结尾 · 保护海岸承诺 | 自动 | 普通提示（非强制） |

自动播放与人工讲解在中途交错；冷启动后两个 ⚠ 强制安全事实
（`ack:safety-entry`、`ack:touchpool-rules`）必须重新确认。

## 运行

环境要求：Node 18+（开发于 Node 22）。

```bash
npm install
npm run dev        # 打开终端输出的本地地址（默认 http://localhost:5173）
```

其他命令：

```bash
npm test           # 一次性运行全部测试（Vitest）
npm run test:watch # 监听模式
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览生产构建
```

> 如果本机 npm 缓存目录权限异常，可指定临时缓存：
> `npm install --cache /tmp/npm-cache`

## 推荐验收路径（30 秒复现现场问题）

1. 点 **开始流程** → 触摸确认入口安全提示。
2. 用 16× 倍速 + 「下一步」走到 **#6 触摸池喂食演示**。
3. 点 **讲解中途断电**，再点 **上电恢复**：
   - 屏幕不会停在喂食演示，而是**回退到入口安全提示**；
   - 右侧「恢复前后差异」列出失效的安全事实与回退 5 页；
   - 未重新确认前，下一步、超时都无法推进。
4. 或在任何时候点 **强进喂食演示（跳过规则确认）**：
   操作被守卫阻断，右侧出现红色阻断原因与缺失事实。
5. 刷新浏览器：三块屏均按冷启动策略恢复，不依赖服务器。

## 关键设计

| 关注点 | 实现位置 | 做法 |
|--------|----------|------|
| 状态转换 | `src/engine/engine.ts` `reduce()` | 纯函数 reducer；非法/不适用动作返回原引用 |
| 前置条件守卫 | `enterScreen()` / `missingRequires()` | 缺事实则位置不动，登记 `blocked` 原因 |
| 计时暂停 | `TICK` 仅在 `running` 累加 | `paused/interrupted/off` 时时钟冻结；单步 TICK 上限 60s 防跳帧穿透 |
| 幂等触发 | `FlowState.pendingAck` | 每次进入提示用事件序号刷新 nonce，确认后立即清零；nonce 不符原样返回 |
| 冷启动恢复 | `coldBoot()` | 拒绝 flowId 不符的注入；强制安全事实（静态清单 ∪ 所有 required 提示）失效；回退到最早强制提示页 |
| 恢复差异 | `diffRecovery()` | 对比屏幕、状态、失效事实、回退页数 |
| 撤销重做 | `src/engine/history.ts` + `src/state/kiosk.ts` | 快照栈（上限 100）；离散动作入栈，TICK 仅跨页时入栈 |
| 刷新恢复 | `src/engine/storage.ts` + `restoreKiosk()` | `localStorage` 按 kiosk 存键，启动时统一走 `coldBoot` |

引擎（`src/engine/`）是完全不依赖 React/DOM 的纯 TypeScript，
React 层（`src/state/`、`src/components/`）只负责驱动与展示。

## 测试

`src/engine/engine.test.ts`、`src/engine/storage.test.ts` 共 26 个用例，覆盖：

- **状态转换**：开始、自动到时翻页、人工页必须下一步、完整八页走通、非法动作不变；
- **计时暂停**：提示阻塞时不计时、暂停冻结、恢复后续播且不丢事实；
- **幂等触发**：重复触摸、陈旧/伪造 nonce、重复到时信号、nonce 刷新后旧事件失效；
- **恢复**：断电拒绝一切动作、冷启动移除安全事实并回退、不可用旧 nonce 绕过、
  差异报告、注入异流程状态被拒、自定义强制提示同样重验；
- **流程阻断**：跳过全景被拦、未确认规则不能进喂食演示、阻断态计时冲不开关卡；
- **撤销重做**：历史往返、新提交清空 future、撤销会连带回退已完成事实；
- **持久化**：存档往返、按 kiosk 隔离、损坏数据安全降级。

## 目录结构

```
src/
  engine/            # 纯 TS 核心，无 React 依赖
    types.ts         # 流程/状态/动作类型
    coastalFlow.ts   # 内置「海岸生态展」流程
    engine.ts        # reducer、守卫、幂等 nonce、冷启动、恢复差异
    history.ts       # 撤销/重做快照栈
    storage.ts       # localStorage 持久化
    *.test.ts        # 引擎与持久化测试
  state/
    kiosk.ts         # 应用层：三块屏、计时、撤销、恢复、持久化编排
  components/        # 模拟屏、控制甲板、时间线、事实/阻断、恢复差异、页面编辑、日志
  App.tsx
  main.tsx
  styles.css
```
